# 마크다운(Markdown) 예시 정리 문서

> 이 파일은 마크다운 기본 문법과 예시를 한 번에 볼 수 있도록 만든 예제입니다.

---

## 1. 제목(Heading)

마크다운에서 제목은 `#` 기호의 개수로 단계(레벨)를 구분합니다.

```markdown
# 제목 1
## 제목 2
### 제목 3
#### 제목 4
##### 제목 5
###### 제목 6
```

렌더링되면 대략 다음과 같이 보입니다.

# 제목 1
## 제목 2
### 제목 3
#### 제목 4
##### 제목 5
###### 제목 6

---

## 2. 문단과 줄바꿈

- 문단(paragraph)을 나누려면 **빈 줄 한 줄**을 넣습니다.
- 같은 문단 안에서 줄바꿈만 하고 싶으면 문장 끝에 `공백 2개` 후 엔터를 사용하기도 합니다(플랫폼마다 다를 수 있음).

```markdown
이것은 첫 번째 문단입니다.

이것은 두 번째 문단입니다.  
이 줄은 같은 문단 안에서 줄바꿈만 한 예시입니다.
```

## 3. 목록(List)

### 3-1. 순서 없는 목록 (Unordered List)

`-`, `*`, `+` 중 아무거나 사용 가능합니다.

```markdown
- 항목 A
- 항목 B
  - 하위 항목 B-1
  - 하위 항목 B-2
* 항목 C
+ 항목 D
```

렌더링 예시:

- 항목 A
- 항목 B
  - 하위 항목 B-1
  - 하위 항목 B-2
* 항목 C
+ 항목 D

### 3-2. 순서 있는 목록 (Ordered List)

숫자 + `.` 조합으로 작성합니다.

```markdown
1. 첫 번째 단계
2. 두 번째 단계
3. 세 번째 단계
   1. 세부 단계 3-1
   2. 세부 단계 3-2
```

렌더링 예시:

1. 첫 번째 단계
2. 두 번째 단계
3. 세 번째 단계
   1. 세부 단계 3-1
   2. 세부 단계 3-2

## 4. 텍스트 강조(Emphasis)

굵게, 기울임, 취소선 등을 표현할 수 있습니다.

```markdown
*기울임* 또는 _기울임_

**굵게** 또는 __굵게__

***굵고 기울임*** 또는 ___굵고 기울임___

~~취소선~~
```

렌더링 예시:

- *기울임* 또는 _기울임_
- **굵게** 또는 __굵게__
- ***굵고 기울임*** 또는 ___굵고 기울임___
- ~~취소선~~

## 5. 링크와 이미지

### 5-1. 링크(Link)

```markdown
[링크 텍스트](https://example.com)

[구글](https://www.google.com)
```

렌더링 예시:

- [링크 텍스트](https://example.com)
- [구글](https://www.google.com)

### 5-2. 이미지(Image)

이미지는 링크 문법 앞에 `!`만 붙이면 됩니다.

```markdown
![대체 텍스트](https://via.placeholder.com/150 "툴팁 텍스트")
```

렌더링 예시(일부 환경에서는 미리보기가 안 보일 수 있음):

![대체 텍스트](https://via.placeholder.com/150 "툴팁 텍스트")

## 6. 코드(Code)

### 6-1. 인라인 코드(Inline Code)

문장 안에 짧은 코드를 넣을 때는 **백틱(`)** 으로 감싸줍니다.

```markdown
파이썬에서 리스트 길이는 `len()` 함수로 구합니다.
```

렌더링 예시:

파이썬에서 리스트 길이는 `len()` 함수로 구합니다.

### 6-2. 코드 블록(Code Block)

여러 줄의 코드를 표현할 때는 세 개의 백틱을 사용합니다.

#### (1) 언어 미지정

```markdown
```
여기에
그냥 코드처럼
보이고 싶은 텍스트를 씁니다.
```
```

#### (2) 언어 지정

```markdown
```python
def add(a, b):
    return a + b

print(add(2, 3))
```
```

렌더링 예시:

```python
def add(a, b):
    return a + b

print(add(2, 3))
```

> 주의: 실제 마크다운 파일을 작성할 때는, 코드 블록 안의 ``` (백틱 3개)와 겹치지 않도록 유의해야 합니다.

## 7. 인용구(Blockquote)

앞에 `>` 기호를 붙이면 인용구가 됩니다.

```markdown
> 이것은 인용문입니다.
> 여러 줄 인용도 가능합니다.
>> 이렇게 중첩 인용도 가능합니다.
```

렌더링 예시:

> 이것은 인용문입니다.  
> 여러 줄 인용도 가능합니다.  
>> 이렇게 중첩 인용도 가능합니다.

---

## 8. 수평선(Horizontal Rule)

`---`, `***`, `___` 등으로 구분선을 넣을 수 있습니다.

```markdown
문단 1

---

문단 2

***

문단 3

___

문단 4
```

## 9. 표(Table)

기본 표 문법은 다음과 같습니다.

```markdown
| 열1 제목 | 열2 제목 | 열3 제목 |
|---------|----------|----------|
| 데이터1 | 데이터2  | 데이터3  |
| 데이터4 | 데이터5  | 데이터6  |
```

렌더링 예시:

| 열1 제목 | 열2 제목 | 열3 제목 |
|---------|----------|----------|
| 데이터1 | 데이터2  | 데이터3  |
| 데이터4 | 데이터5  | 데이터6  |

### 9-1. 정렬 옵션

`:` 위치에 따라 왼쪽/가운데/오른쪽 정렬을 지정할 수 있습니다.

```markdown
| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:---------|:-----------:|-----------:|
| 값1      | 값2         | 값3        |
| 값4      | 값5         | 값6        |
```

렌더링 예시:

| 왼쪽 정렬 | 가운데 정렬 | 오른쪽 정렬 |
|:---------|:-----------:|-----------:|
| 값1      | 값2         | 값3        |
| 값4      | 값5         | 값6        |

## 10. 체크박스(Task List)

GitHub 등 일부 플랫폼에서는 체크리스트를 지원합니다.

```markdown
- [ ] 해야 할 일 1
- [x] 이미 완료한 일 2
- [ ] 해야 할 일 3
```

렌더링 예시(플랫폼에 따라 체크박스로 표시됨):

- [ ] 해야 할 일 1
- [x] 이미 완료한 일 2
- [ ] 해야 할 일 3

## 11. 수식(Math, 일부 플랫폼 전용)

일부 플랫폼(예: GitHub, Jupyter, 특정 플러그인)에서는 LaTeX 스타일 수식을 지원합니다.

### 11-1. 인라인 수식

```markdown
인라인 수식 예시: $y = ax^2 + bx + c$
```

렌더링 예시(지원되는 환경에서):

인라인 수식 예시: $y = ax^2 + bx + c$

### 11-2. 디스플레이 수식

```markdown
$$
y = ax^2 + bx + c
$$
```

렌더링 예시(지원되는 환경에서):

$$
y = ax^2 + bx + c
$$

## 12. 실제 문서 예시 1 – 회의록 템플릿

아래는 협업용 회의록을 마크다운으로 작성한 예시입니다.

```markdown
# 2025-12-01 팀 회의록

## 1. 개요
- 일시: 2025-12-01 10:00–11:00
- 참석자: A, B, C
- 장소: 온라인(Google Meet)

## 2. 안건
1. 4분기 서비스 런칭 일정 점검
2. 신규 기능 요구사항 정리
3. 다음 액션 아이템 정의

## 3. 논의 내용

### 3-1. 4분기 서비스 런칭 일정
- 베타 테스트: 12/10 ~ 12/20
- 정식 오픈: 12/30 예정
- 우선순위 기능:
  - 회원 가입/로그인
  - 결제 모듈 안정화
  - 대시보드 기본 통계

### 3-2. 신규 기능 요구사항
- 관리자 페이지에서 유저 검색 기능 추가
- 다운로드 리포트에 필터 옵션 추가

## 4. 액션 아이템

- [ ] A: 베타 테스터 목록 확정 및 초대 메일 발송 (12/05까지)
- [ ] B: 결제 모듈 오류 로그 정리 및 이슈 티켓 발행
- [ ] C: 대시보드 통계 항목 정의 및 기획서 초안 작성

## 5. 비고
- 다음 회의: 2026-01-05(월) 10:00
```

## 13. 실제 문서 예시 2 – 기술 문서(README) 템플릿

```markdown
# 프로젝트 이름(Project Name)

간단한 프로젝트 소개 문장을 여기에 작성합니다.

## 1. 소개(Overview)
- 이 프로젝트는 무엇을 하는가?
- 누가 사용할 것인가?
- 왜 만들었는가?

## 2. 주요 기능(Features)
- 기능 1: 설명
- 기능 2: 설명
- 기능 3: 설명

```bash
# 저장소 클론
git clone https://github.com/username/repo.git
cd repo

# 의존성 설치
pip install -r requirements.txt
```

```bash
python main.py --help

from project import run

```text
project-root/
├─ src/
│  ├─ __init__.py
│  ├─ main.py
│  └─ utils.py
├─ tests/
│  └─ test_main.py
├─ README.md
└─ requirements.txt
```

- MIT, Apache-2.0 등 원하는 라이선스 명시
```

## 15. 마크다운 작성 팁

1. **일관성 있는 제목 구조 사용**
   - 큰 제목은 `#`, 하위 섹션은 `##`, `###` 순서로 통일
2. **목차를 활용**
   - 긴 문서는 맨 위에 목차를 두면 읽기 편합니다.
3. **코드와 설명을 번갈아 배치**
   - 코드 블록, 결과 이미지, 설명을 묶어서 적으면 이해도가 올라갑니다.
4. **표와 리스트로 정보 구조화**
   - 나열되는 정보는 표 또는 목록으로 재구성하면 훨씬 보기 좋습니다.
5. **버전 관리와 함께 사용**
   - GitHub, GitLab 등과 함께 사용하면 변경 이력 관리에도 좋습니다.
